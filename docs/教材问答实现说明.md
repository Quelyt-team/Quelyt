## 1. 用户现在会看到什么

| 操作 | 当前行为 |
| --- | --- |
| 打开一本教材，切到“问答” | 显示“教材问答”，默认“全书＋联网”；不再要求先选择“当前页／本次页段” |
| 停留在任意一页问另一章的知识 | 自动检索整本书；当前页只作为排序和指代提示，不截断范围 |
| 问某种方法的“为什么” | 教材只有结论时，先查全书，再真实搜索并读取网页；回答区分教材原文、外部资料和解释 |
| 问“作者到底有没有说” | 自动切到严格核查模式：只依据教材原文，不发送搜索，不用外部资料补写作者观点 |
| 连续追问 | 保留教材会话和上一轮来源；翻页、改学习小节不清空 |
| 切换到另一本教材 | 默认切换到该教材自己的会话；原会话保留在本地 |
| 网络失败、未配置、仅缓存 | 分别显示“联网未完成／未联网／使用缓存网页”，仍给出有教材依据的解释，不伪造链接 |
| 建立教材理解 | 逐块整理章节、定义、结论、条件和术语；可查看进度、全书概览、章节与知识点；可取消、可续跑 |

## 3. 存储与迁移

数据库从 v6 升到 v7，新增：

- `book_understanding_jobs`：每本教材一个整理任务、状态和概览；
- `book_chapters`、`book_chunks`：章节和页段分块、摘要、来源摘要指纹；
- `book_knowledge_points`：稳定 ID、术语、英文别名、符号、页段、定义；
- `book_qa_conversations`、`book_qa_messages`：教材会话与逐轮问答；
- `web_source_cache`：实际读取过的网页正文，按 URL 哈希保存。

删除教材时上述表通过外键级联删除；`web_source_cache` 是全局缓存，可独立按时间清理。迁移沿用现有的 `VACUUM INTO` 备份 + `integrity_check` + 事务，v6→v7 失败会回滚并保留 v6 备份。

旧 `history:<documentId>` 的问答在第一次打开教材问答时导入一次：保留问题、回答、原页来源和时间，标注“旧版记录”；原设置不删除，便于回滚。导入不会把旧回答升级为新的教材引用。

## 4. 建立教材理解

1. `ensureStructure` 只做本地工作：读取已有页文字，生成章节和分块，不调用模型。
2. 章节优先从页面首行的“第 N 章／Chapter N／数字加标题”识别；识别不到时按 20 页一段生成临时章节。页面上的小节目录不会强行拆章。
3. 章节可在“查看教材理解 → 编辑章节”中修改标题和起始页；保存后必须连续覆盖第 1 页到最后一页，受影响的分块会重建。
4. 每个分块最多 8 页、约 9,000 字符；超过时拆成新块，单页过长时在请求中明确标注“本块后半文字未发送，需回看原页”，并记录截断标记。
5. 一次运行默认最多 40 个分块；处理完一块立即保存，剩余分块保持 pending。下一轮继续，不会因为 40 块上限丢掉后半本。
6. 每个分块返回摘要、定义、结论、条件、典型题型和术语；术语按“章节 + 规范化术语”合并，保留英文别名、符号和页段。
7. 全部块完成后生成全书概览（学科范围、定义约定、章节关系、主线、未完成项）。
8. 页面文字被校正后，分块通过来源摘要指纹检测失效；只重建受影响分块，同时清除该章旧知识点和旧概览，避免拿过期概览回答。
9. 封面／空白页可在概览里“标记空白页”，明确记为已处理，不假装有正文。
10. 连续 3 个分块失败会停止本轮，避免持续计费；失败分块保留错误，可继续。

说明：当前还没有读取 PDF 目录树，也没有把图表理解纳入自动整理；未处理图页不会被声称“已读懂”。

## 5. 全书检索

一次提问的检索步骤：

1. 分析问题类型：原因、举例、最新、作者原话、跨章关系。
2. 去停用词后拆出中文双字词和多字概念；匹配知识点术语、英文别名、符号和章节标题。
3. 多路召回：完整问题、概念/别名、拆解词、原因增强词、命中章节标题、知识点所在页；全部在整本教材范围内执行（“只看当前页”模式除外）。
4. 知识点页和章节起始页直接取原文，避免问题用词与教材用词不同而漏页。
5. 对排名靠前的命中页补一页相邻上下文，支持跨页解释。
6. 按相关性、页多样性、12 段／16,000 字符预算截取；不把无关片段凑数。
7. 覆盖范围由客户端计算：已解析页数、未解析页段、尚未整理章节、是否真的检索全书；检索不到时区分“暂未检索到”和“全书已充分核查”。

当前使用 FTS5 + 知识点/章节辅助召回，没有引入向量库。方案要求先验证召回质量；本轮合成样例已覆盖跨页、别名、当前页提示和缺页场景。真实教材若出现明显同义漏召回，再按方案加入多语种向量检索。

## 6. 联网搜索

### 6.1 接口

| 项目 | 实现 |
| --- | --- |
| 搜索 | `POST https://api.deepseek.com/v1/tools/search`，`query`、`count=5`、`need_content=true`、`ori_question` |
| 读取 | `POST https://api.deepseek.com/v1/tools/fetch`，`{"url": ...}` |
| 认证 | 复用当前 DeepSeek 设置的系统凭据；凭据只发送到 `api.deepseek.com` |
| 路由 | 固定官方地址；非 DeepSeek 服务商返回 `notConfigured`，不尝试官方路径，也不借用其他 Key |

搜索响应读取 `title`、`url`、`snippet`、`summary`、`content`、`site_name`、`date`、`authority`、`rerank_score`；读取响应读取 `title`、`content`。所有 URL 必须是 HTTP(S)、无用户名密码；本机、私有网段和 `.local` 会被拒绝，避免把本机地址交给外部服务。

### 6.2 预算与来源

- 每题最多 2 条互补搜索词、3 次网页读取、4 个来源、1 次最终回答。
- 搜索已返回正文时直接使用并写入缓存；没有正文才读取网页。
- 读取失败时可以使用搜索摘要，但标为“仅摘要”，不能算“已读正文”。
- 7 天内的缓存可用于同一问题；时效性问题（最新／今年／进展等）跳过缓存重新读取。
- 所有来源状态由客户端记录，模型不能自报“已搜索”。网络失败时仍用教材证据生成回答，并明确标注联网未完成。
- 搜索词只发送概念与意图，不带整页教材、完整书名、笔记或学习记录。最终回答请求会包含本次选中的教材片段和已读取的网页片段；这两类来源在预览与回答中分别列出。

费用：Search／Fetch 按成功请求计费，最终回答按 token 计费；界面分别显示搜索次数、读取次数和回答 token，不把三者混成一个数字。

## 7. 问答契约

新增独立 `bookQuestion` 请求（`BookQaClient`），不使用通用 `AiTask.explain` 的“无引用即失败”规则。模型返回：

```json
{
  "answerStatus": "answered|partial|needsClarification",
  "blocks": [
    {
      "text": "回答段落",
      "bookCitations": ["B1"],
      "webCitations": ["W1"],
      "supplemental": false
    }
  ],
  "bookCoverage": {
    "scope": "模型实际依据的教材范围",
    "matchedChapters": ["章节名"],
    "gaps": ["仍未覆盖的部分"]
  },
  "missingInformation": ["真正影响回答的未知条件"]
}
```

客户端负责：

- 从本次实际选中的教材证据生成 `B1…Bn`，从实际搜索/读取的来源生成 `W1…Wn`；
- 拒绝不在注册表中的编号，不生成可点击链接，并把回答降为“部分回答”；
- 覆盖范围使用客户端真实的页数、章节缺口和检索范围，不采用模型夸大的“全书已核查”；
- 没有引用不再自动判失败：教材只给结论、解释来自可靠外部资料时仍可正常回答；
- 作者原话核查使用独立严格提示词，禁止网络来源和外部推断。

来源快照保存原始页区域、文字、文档版本和获取时间；点击教材出处回到原页，点击网络来源打开浏览器；URL 无法打开时复制链接。

## 8. 会话、取消和晚到结果

- 教材会话绑定 `documentId + contentHash`，翻页和学习小节变化不重建。
- 提问先落库为 question，再发网络请求；取消后保留问题并标记“已取消”。
- 结果写回发起请求时的会话；即使期间切到另一本书，也不会写进新书的会话。
- 切换教材后，原会话的回答仍保存在数据库，回到原书可读。
- 最终回答请求一旦发出无法撤回；界面会说明“结果仍会保存”，不宣称已中止计费。

## 9. 界面

- 问答页标题旁显示教材整理状态；未完成时显示覆盖说明和“建立／继续整理”。
- 生成中按“查找教材 → 检索网络 → 阅读来源 → 整理回答”显示阶段，并允许停止。
- 框选原页图表或公式后，问答输入区出现“问这张图”；预览会显示实际像素，确认后只授权本次图片。视觉模型回答进入同一教材会话，图片不写入数据库。
- 回答上方显示回答状态和联网状态；正文按段落显示，“解释与补充”明确标记；下方分列“教材出处”和“网络参考”。
- 网络参考可展开，显示标题、站点、日期、正文／摘要／缓存状态、URL、打开和复制。
- 发送前预览显示教材范围、原文段数、搜索词、服务商、搜索/读取/回答上限，并明确“搜索后才会取得网页正文”。
- 概览中可查看页面解析完成度、知识整理完成度、章节（临时章节会标注）、知识点、编辑章节、标记空白页。
