# Quelyt 笔记系统实现说明

实施日期：2026-11-10。对应方案：[笔记系统完善实施计划](../笔记系统完善实施计划.md)。本轮交付的是**可日用的第一版**：独立笔记、旧笔记迁移、全局入口、自动保存、来源引用、文件夹／标签、搜索和回收站；方案中的富文本图片、AI 整理、问答保存、课程与复习联动仍在后续。

## 1. 已实现

- **独立笔记**：笔记不再要求绑定资料；标题、正文、创建／更新时间、星标和生命周期独立保存。可空白、仅问题或仅摘录。
- **旧笔记迁移**：schema v9 把旧 `notes` 表迁移为 `note_documents`、`note_entries`、`note_sources`、`note_questions` 和初始历史版本；保留旧 ID、资料 ID／哈希、页码、选区和摘录。旧表不删除，迁移前仍使用 v8 快照。
- **全局入口**：侧边栏和窄屏底部导航新增“笔记”。三栏为范围／文件夹树、笔记列表和编辑器；窄屏列表与编辑逐级切换。
- **自动保存**：编辑暂停 700 ms 后落盘；切换笔记、切换范围、离开页面、应用进入后台和退出时主动刷新。界面只在写入成功后显示“已保存”；失败显示“保存失败”并保留当前内存内容。保存携带修订号，过期编辑不会覆盖新内容。
- **编辑**：标题、Markdown 正文、常用格式工具栏（标题、粗体、斜体、列表、待办、引用、代码、公式、链接）、六类模板、修改后自动更新摘要。宽屏把正文与来源／问题分为双栏，窄屏回落为下方卡片；提供 Markdown 预览。公式以 Markdown `$$` 源码保存，本轮不做公式可视化编辑。
- **来源**：阅读器选中原文创建笔记时保存资料 ID、哈希、页码、选区、摘录和标题；笔记页显示来源卡，可回到原页；来源资料被删或版本变化时给出明确提示，正文不丢。
- **分类**：可放入资料库共用的彩色文件夹，移动只改变入口；标签与资料库共用，可新建；支持星标。
- **查找**：搜索标题、正文、标签和来源摘录；范围有全部、最近编辑、星标、未归档、文件夹、回收站。
- **问题**：一篇笔记可记多个待解决问题，有未解决／已解决状态；勾选解决不会改变日程或知识点掌握度。
- **历史版本**：创建、自动保存（5 分钟节流）和恢复前留有快照；可查看时间／原因并恢复为新版本。自动版本最多保留 100 个；手动命名保留尚未做。
- **回收站**：移入、恢复和永久删除；恢复优先原文件夹，文件夹不存在则回到未归档；删除快捷方式规则尚未实现。
- **阅读器**：原“记笔记”弹窗仍可快速记录，但写入新笔记模型；允许只写问题或只留摘录；阅读面板读取当前资料相关的已保存来源。
- **导出**：可复制当前笔记的 Markdown（含来源标题、页码和摘录）。

## 2. 数据结构

| 表 | 作用 |
| --- | --- |
| `note_documents` | 正文、标题、格式版本、修订号、星标、生命周期、时间戳 |
| `note_entries` | 主文件夹入口；复用 `library_folders`；每篇一个主入口 |
| `note_sources` | 资料／页码／哈希／选区／摘录快照；`document_id` 不设级联外键 |
| `note_questions` | 待解决问题及状态 |
| `note_tags` | 与 `library_tags` 共用标签 |
| `note_revisions` | 历史正文、来源状态快照 |

正文列是当前值，`data` JSON 同步保存完整对象；因此数据库快照、整库备份和恢复不需要额外附件表。当前 Markdown 正文没有独立图片附件。

## 3. 边界与后续

- 尚未实现 Flutter Quill 富文本、图片嵌入、附件、公式渲染预览和查找替换。
- 尚未实现问答“保存到笔记”、笔记内 AI 辅助、笔记链接／反向链接、每日课程关联、复习任务、笔记包导入导出。
- 文件夹快捷方式、混合资料／笔记拖拽、批量回收和统一计数尚未接入资料库树；笔记页使用自己的文件夹树。
- Windows 已构建并启动验证；Android 真机、输入法、长按和软键盘仍未验收。

- Windows Release `0.3.0-dev+33` 构建并覆盖安装；启动后真实资料库从 v8 升级到 v9，`integrity_check=ok`，旧资料数量保持。
