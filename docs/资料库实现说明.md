## 2. 数据模型

SQLite schema 从 v7 升到 v8（资料库），再由 v8 升到 v9（独立笔记）。升级前继续使用 `VACUUM INTO` 备份并校验；失败回滚，不出现半迁移。笔记表与旧笔记迁移见[笔记实现说明](笔记实现说明.md)。

新增表：

| 表 | 作用 | 关键约束 |
| --- | --- | --- |
| `library_folders` | 应用内文件夹树、颜色模式、图标、说明、手动顺序、删除批次 | 同级规范化名称唯一；父级不能指向自身或后代（控制器层校验）；技术上限 64 层 |
| `document_entries` | 资料入口：一个主入口＋多个快捷方式 | 每份有效资料最多一个主入口；同一文件夹不重复放同一资料入口；快捷方式别名只影响该入口 |
| `library_tags` / `document_tags` | 跨文件夹标签 | 标签改名不改变关联；删除标签不删除资料 |
| `deletion_batches` | 一次删除的影响范围与原始根 | 恢复按批次还原文件夹、颜色、顺序、入口与资料状态 |
| `import_batches` / `import_items` | 导入日志、状态、暂存路径、进度 | 关闭应用后已完成项仍可查看；未完成项标为“待继续” |

`documents` 新增列：`original_name`、`format`、`size_bytes`、`lifecycle`、`lifecycle_version`、`starred`、`learning_mode`、`added_at`、`deleted_batch`、`trashed_at`。`kind` 保留作兼容字段，含义改为学习方式偏好：`unspecified`、`textbook`、`paper`。

**身份规则：** 移动、改名、改色、换标签、建快捷方式都不改变 `documentId`、内容哈希和托管路径。内容变化只能作为新资料导入；旧笔记、页码引用不自动搬运。

**未归档：** 主入口位于逻辑根目录的有效资料。**全部资料：** 按 `documentId` 去重。**文件夹：** 按入口查询，快捷方式只在真实文件夹里出现一次。

## 3. 导入

### 3.1 流程

```text
选择文件 / 选择文件夹 / 从资源管理器拖入书库
        ↓
扫描（目录：文件数、支持数、大小、不支持与无法读取清单；不跟随符号链接）
        ↓
用户确认目标与范围
        ↓
逐项：暂存到应用 imports/<batch>/ → 流式复制并报进度
        ↓
SHA-256 → 事务内查重 → 移入 documents/<id>/original.ext → 写资料与主入口
        ↓
放置到目标文件夹（或根目录）→ 后台 OCR 仍由阅读器/日程按需触发
```

- 导入与打开分离；批量导入不会逐份打开阅读器。
- 单份失败不回滚已成功项目；取消剩余不删除已入库资料。
- 不支持的格式列入结果清单并写明原因，不静默漏掉。
- 目录导入默认新建一个同名文件夹；若同级已有同名文件夹，则为 `名称 (2)`，不静默合并。
- 暂存副本在 `imports/`，应用重启后未完成项可从暂存继续；来源权限失效时允许重试重新选择。

### 3.2 查重

以托管副本的哈希为准，不看文件名：

| 情况 | 结果 |
| --- | --- |
| 目标位置没有该资料 | 新资料＋主入口 |
| 内容已在目标文件夹 | “已存在”，不复制、不新建入口 |
| 内容在另一个文件夹 | “已存在”，在该文件夹建立快捷方式并提示 |
| 内容在回收站 | “已存在”，不自动恢复；到回收站处理 |
| 名称相同、内容不同 | 保留两份，正常导入 |

历史重复资料不做迁移时归并；各自的学习记录保留。

## 4. 文件操作

- **文件夹**：新建、子文件夹、重命名、移动、上移/下移、颜色与 emoji、说明、删除到回收站、解散并保留资料、导出文件夹结构。
- **资料**：阅读、重命名（显示名，不改格式/外部文件）、移动到、创建快捷方式、星标、标签、详情、导出原件、移入回收站。
- **快捷方式**：别名、定位原资料、只删除该入口。
- **选择**：Ctrl 多选、Shift 连选、Ctrl+A 全选；触屏长按进入多选；切换文件夹或筛选会清空不可见选择。
- **每文件夹视图**：列表／网格、排序字段与方向按文件夹记住，新文件夹沿用全局默认；重启恢复。
- **拖拽**：资料/文件夹拖到树节点、文件夹卡片或面包屑；手动顺序下拖到资料行或文件夹同级插入线可调整顺序；从资源管理器拖入文件/文件夹导入当前文件夹。
- **撤销**：Ctrl+Z 撤销最近一次移动、重命名或移入回收站；SnackBar 提供同样入口。永久删除不提供撤销。
- **键盘**：Enter 打开、F2 重命名、Delete 移入回收站、Ctrl+A 全选、Ctrl+X/C/V 移动、Ctrl+Shift+N 新建文件夹、Esc 取消选择。文本框聚焦时按键遵循文本编辑。

## 5. 删除、恢复与清理

- 默认删除是软删除：资料/文件夹/入口带 `deleted_batch` 与时间戳；资料进入 `trashed` 并提升 `lifecycle_version`。
- 删除资料主入口会移走资料；其他文件夹里的快捷方式保留并显示“资料在回收站”。
- 删除快捷方式只移走该入口。
- 删除文件夹按批次包含子文件夹、入口和主资料；外部快捷方式保留。
- 恢复整批：文件夹、颜色、图标、手动顺序、入口、资料一起恢复；原父级已不存在时放到根目录并提示。
- 永久删除：先阻断写入并记录 `pending-delete`，事务删除资料/入口/文件夹/删除批次，再释放 `documents/<id>` 与 `caches/<id>`。外部原文件始终不动。
- 日程任务保留文字与历史，材料引用标记缺失；独立学习记录（`learning_records`）不随资料删除。
- 搜索、普通列表、阅读打开和后台索引只读 `active`。晚到 OCR/问答结果通过生命周期版本拒绝写回。

## 6. 搜索与筛选

- 范围：当前文件夹、包含子文件夹、全部资料；输入框旁的按钮显示并切换范围。
- 元数据：标题、原始文件名、文件夹名、说明、标签。
- 正文：复用现有 FTS5，返回片段与真实页码，点击打开资料并跳到该页；只包含活动资料。
- 覆盖提示：命中资料仍有未识别页面时显示“正文搜索可能不完整”，不把“找不到正文”说成资料没有该内容。
- 筛选：格式、标签、仅星标、仅待处理、仅未读；清除筛选不影响资料。
- 回收站有独立搜索框（顶部搜索在该视图按批次标签和资料名过滤）。

- **智能文件夹**：把当前搜索词与筛选（格式、标签、星标、未读、待处理）保存为条件；树中独立分组，顶部提示当前条件，结果随资料变化。保存的是查询而不是资料副本，不能向其中拖动，删除条件不影响资料。

## 7. 导出、备份与恢复

- 选中资料导出原件：每份资料只复制一次，文件名使用显示名＋原扩展名；冲突追加 ` (2)`；Windows 保留名追加下划线；非法字符替换为 `_`。
- 选中文件夹导出结构：在目标位置建立同名根目录与子目录，资料放入其真实入口目录；快捷方式不重复复制，报告里说明跳过数量。
- 流式复制，完成后统计字节；失败保留失败清单，不冒充全部成功。
- 拒绝把应用托管目录选为导出位置，避免覆盖正在读取的原件。
- 导出不等于学习数据备份：笔记、问答、日程不包含在原件导出中。

### 7.1 整库备份与恢复

- **备份**：`VACUUM INTO` 一致性数据库快照＋托管原件＋`manifest.json`（格式版本、数据库版本、文件大小与 SHA-256、回收站计数）；默认包含回收站，可显式排除。备份含笔记、问答、课程、日程、文件夹树、颜色、标签与视图设置；API Key 在系统凭据库，不进入备份。写完后立即用同一校验器自检，失败删除临时包，不冒充成功。
- **恢复**：先校验清单、数据库完整性、应用版本和每个原件哈希，再把包复制到应用内暂存并写恢复请求；真正替换发生在**下次启动、数据库打开之前**，所以不会有阅读器或 OCR 正在使用旧文件。当前 `study.sqlite3`、`documents`、`cache`、`imports` 整体移动到 `pre-restore-<时间戳>`，再安装备份；任一步失败按移动记录回滚，旧库仍然可用。成功或失败都写 `restore-result.json`，设置页可查看。
- **跨机器路径**：恢复后资料 ID、哈希和页码引用不变；启动时按资料 ID 重建托管路径，不沿用旧电脑绝对路径。
- **边界**：恢复是整库替换，不与当前库合并；恢复后模型凭据需重新配置。

### 7.2 存储与原件修复

- 设置页的“存储与原件修复”显示原件、可重建缓存（缩略图/页面渲染/OCR 临时文件）、数据库、回收站资料数量与占用；清理前再次确认，清理只删除 `cache` 内的可重建文件，不动 SQLite 中的文字、笔记、问答和日程。
- 缺失原件列表来自托管目录核对；重新链接只接受 SHA-256 与资料记录完全一致的文件，写回 `documents/<id>/original.ext` 并更新路径。内容不同会被拒绝，必须作为新资料导入，避免页码与笔记错配。

## 8. 学习方式与旧资料

- 导入不再询问教材／论文；新资料 `kind = unspecified`，默认进入“阅读与问答”通用路径。
- 阅读器第一页提供“教材自学／论文精读”入口，右上角菜单可随时切换；切换只改路由，不清空笔记、问答、作答和阅读位置。
- 旧 `textbook`/`paper` 保留原学习方式；旧会话按原流程恢复。
- `book_qa` 入口只在用户明确选择“教材自学”后出现，避免把普通资料当作教材自动理解。
- 文件夹名称、颜色、标签不推断学习方式。

## 11. 已知限制与下一步

1. **操作系统拖入**已在 Windows 接入 `desktop_drop 0.8.4`，但尚未在真实资源管理器完成多文件/目录与中文长文件名的手工验证；Android 拖入和“拖到具体文件夹目标”未验收。
2. **空间管理**已提供占用统计、缓存清理与缺失原件重新链接；没有按文件浏览占用、缩略图单独清理和“打开所在文件夹”入口。
3. **文件夹封面**按计划列为后续增强；资料首屏封面在详情与网格懒加载并缓存，缓存清理后按需重算。
4. **Android 真机**与窄屏触控、大字体未验收；桌面键盘、长按多选与拖拽已在 widget 测试覆盖，但仍需实机验收。
5. **性能**未做 10,000 资料/1,000 目录/20 层树压测；当前列表/网格惰性构建、计数聚合查询。
6. **清理阶段 UI**只有成功/失败结果，没有逐阶段进度界面；崩溃恢复靠 `pending-delete` 日志。
7. **导出完成后**没有“打开所在文件夹”动作；失败项只在报告里列出。

以上限制不作为已完成的验收项。下一步优先：外部拖入的真机手工验收、10,000 资料性能压测、文件夹封面与按文件浏览占用。
